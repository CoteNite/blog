## 上下文工程

上下文是Agent的眼睛，它包含着Agent能够使用的所有信息，所有的外界信息必须载入到上下文中才可以被Agent使用，而上下文工程就是治理Agent上下文的工程

官方API的上下文可以分为以下几种：

- 系统提示词: 开发者编写，会被放置在上下文的最顶部，常常会用来定义Agent的行为规则，约束条件等内容，在训练的影响下会被视为最高的优先级
- 用户消息: 用户输入的内容
- 工具调用: 模型之前
