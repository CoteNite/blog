# TS学习心得

随着AI时代的来临，Agent项目规模不断扩大，Py不适合工程的缺点也随之被放大，大厂的Agent项目转投使用TS作为Agent项目的开发语言，Langchain也推出了与py对应的TS版本，TS已经不仅限于前端项目，对于Agent开发也已成必要，浅谈一下TS学习上的一些心得

## 语法上的妥协

在学TS之前，我主要使用的语言是Java/Kotlin，还玩过Scala/js/python等语言，所以学TS的时候常常会感觉一些地方不合理，这给我的学习带来了一定的阻碍，对于这一点，我们要从TS

和Kotlin一样，TS这门语言出生就带有着极强的目的性，那就是代替js，为了尽可能的继承js的全部生态，TS做了很多语法层面的妥协，同时在处理上尽可能不去改动js runtime
